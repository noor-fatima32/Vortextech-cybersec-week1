# 🔐 VortexTech Cyber Security Internship — Week 1

## OWASP Top 10: 5 Critical Web Application Security Risks

This repository contains my Week 1 research assignment for the **VortexTech Cyber Security Internship Program 2026**.

The purpose of this assignment is to research and understand some of the most critical web application security vulnerabilities from the **OWASP Top 10:2025**.

---

# 📌 Assignment Overview

The OWASP Top 10 is one of the most widely recognized cybersecurity awareness documents for web application security. It highlights major security risks that developers and cybersecurity professionals should understand when building and protecting web applications.

For this assignment, I researched five vulnerabilities from the OWASP Top 10:2025 list.

---

# 🎯 Objectives

The objectives of this project were to:

* Understand common web application security vulnerabilities.
* Explain each vulnerability in simple and beginner-friendly language.
* Learn how attackers can exploit these vulnerabilities.
* Research real-world cybersecurity incidents.
* Understand practical prevention and mitigation techniques.
* Build a stronger theoretical foundation in web application security.

---

# 🛡️ Vulnerabilities Covered

| # | OWASP Category | Vulnerability                  |
| - | -------------- | ------------------------------ |
| 1 | A01:2025       | Broken Access Control          |
| 2 | A02:2025       | Security Misconfiguration      |
| 3 | A03:2025       | Software Supply Chain Failures |
| 4 | A05:2025       | Injection                      |
| 5 | A07:2025       | Authentication Failures        |

---

# 📚 Topics Covered

For each vulnerability, the research document includes:

* **What is it?** — A simple explanation of the vulnerability.
* **How could an attacker exploit it?** — Common techniques attackers may use.
* **Real-world example** — A documented cybersecurity incident related to the vulnerability.
* **Prevention and mitigation** — Practical steps developers and organizations can take to reduce the risk.
